# Forever World 3D

A simplified 3D browser game inspired by Fortnite-style survival shooters.

## Run it

Because this uses ES modules and the Three.js CDN, the easiest way to run it is with a local web server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Controls

- W/A/S/D: move
- Mouse: look around
- Left click: shoot
- B: toggle build mode, then click to place a wall
- H: heal with food
- R: restart

## Goal

Collect resources, survive attacks, build defenses, and reach 12 score points.

This is a playable 3D prototype, not a full Fortnite clone, but it has the core feel of a browser-based survival shooter.
